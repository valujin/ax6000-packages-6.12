# Redmi AX6000: vendor Linux 6.12 и пакеты для своей сборки

Две независимые линии на базе
[chasey-dev ImmortalWrt 25.12](https://github.com/chasey-dev/immortalwrt-mt798x-rebase).
Каждая выпускает образы **stock, mtkuboot и ubootmod**, свой SDK и банк модулей.
Разметки не взаимозаменяемы; установка выполняется владельцем вручную.

**Recommended опубликована на APK v3 / ImmortalWrt 25.12.0.** Новое поколение
прошло нативную проверку, отдельный прогон SDK и публикацию Release и подписанного
канала. Полная проверка файлов Pages и активов каталога по HTTPS пройдена.
**Опубликованная latest пока остаётся на OPKG/IPK**.

В установленном recommended обнаружены ошибки загрузки LuCI ASU и проверки
архитектуры/штатного зеркала в установщике feed. Для текущего образа есть
[исправления без перепрошивки](docs/ASU-CLIENT-HOTFIX.md).
Исправленный `luci-app-attendedsysupgrade 20261021.2-r3` опубликован в
подписанном feed recommended и проверен по HTTPS. Обновить только этот пакет
можно по инструкции выше. Готовность публичного ASU-сервера проверяется отдельно.

Формат каждого набора указан в его `profile.json`; старые Releases сохраняются.
Переход OPKG → APK требует новой прошивки, а не замены менеджера пакетов
в работающей системе.

экспериментальной: имеются upstream-сообщения о регрессиях HNAT; успешная

## Образы без встроенного Tailscale

**Tailscale исключён из initramfs и постоянного rootfs всех трёх разметок.**
Он доступен отдельным пакетом своего формата в feed соответствующего поколения
и участвует в ежедневных обновлениях. AmneziaWG, WireGuard, PBR, LuCI и русский
интерфейс остаются в образе согласно `image_packages` source-профиля.

Нативный stock factory UBI помещается в штатный раздел kernel **30 MiB**:

| Поколение | Stock factory UBI | SHA256SUMS |
| --- | --- | --- |
| recommended APK; опубликовано | [18 874 368 байт](https://github.com/valujin/ax6000-packages-6.12/releases/download/firmware-redmi-ax6000-612-recommended-ae65e1de6997-5a57052ba472/immortalwrt-mediatek-filogic-xiaomi_redmi-router-ax6000-stock-initramfs-factory.ubi) | [Суммы нового Release](https://github.com/valujin/ax6000-packages-6.12/releases/download/firmware-redmi-ax6000-612-recommended-ae65e1de6997-5a57052ba472/SHA256SUMS) |
| latest OPKG; опубликованное | [17 825 792 байта](https://github.com/valujin/ax6000-packages-6.12/releases/download/firmware-redmi-ax6000-612-latest-a99b0888b88f-0b1249707848/immortalwrt-mediatek-filogic-xiaomi_redmi-router-ax6000-stock-initramfs-factory.ubi) | [Суммы](https://github.com/valujin/ax6000-packages-6.12/releases/download/firmware-redmi-ax6000-612-latest-a99b0888b88f-0b1249707848/SHA256SUMS) |

Factory UBI, FIT для RAM и sysupgrade имеют разное назначение.
[Ручная проверка и выбор файла](docs/FLASH.md) обязательны перед установкой.
Не применять образы mtkuboot/ubootmod к stock и не менять загрузчик автоматически.

Штатная stock-разметка выделяет **80 MiB** под UBI root. Официальный
Tailscale 1.104.2-r2 занимает около **69,2 MiB после распаковки**, поэтому
не помещается в оставшийся штатный overlay. Доступность пакета не означает,
что его можно установить на stock. Разметка ubootmod имеет UBI около
**122,5 MiB**, но переход на неё — отдельная ручная процедура владельца,
а не рекомендация менять разметку ради пакета. Фактическое свободное место
нужно проверять на устройстве; аппаратные испытания здесь не выполнялись.

## Подключение пакетов

После ручной установки совпадающей прошивки проверить сеть и выполнить
**на роутере от root**. Для recommended APK:

```sh
apk --no-network query --installed --format json --fields name,version kernel
ax6000-install-feed
```

Для текущего опубликованного recommended перед первым запуском необходимо
применить [исправление установщика](docs/ASU-CLIENT-HOTFIX.md): встроенная
копия ещё содержит прежние проверки архитектуры и адреса зеркала.

На опубликованной latest OPKG или прежней recommended OPKG вместо запроса
APK использовать `opkg status kernel`.

Встроенная команда проверяет точный ABI, архитектуру, закреплённый ключ
и подпись индекса; сохраняет настройки своего менеджера пакетов и подключает
feed своей линии. APK сохраняет согласованные feeds `@public`; прежний
OPKG-установщик отключает другие активные feeds. Пакеты, включая Tailscale,
не устанавливаются.
Модули разных линий и Linux 6.6 несовместимы; не подменять зависимость `kernel`.

В recommended APK подключены все пять доступных userspace-feeds **ImmortalWrt
25.12.0**: base, luci, packages, routing, telephony, с тегом `@public`;
feed video не подключён. Kernel, vendor-стек и защищённые зависимости
закреплены на нативных версиях. Для отдельного userspace-пакета:

```sh
apk update
apk add tree@public
apk add iperf3@public
```

`@public` явно выбирает публичный репозиторий; имя пакета остаётся без тега.
Для `iperf3@public` отдельная симуляция выбрала только новые `iperf3` и
`libiperf3` 3.20-r1, без замены защищённых пакетов.
На копии реальной базы и `world` recommended проверена симуляция этой команды:
выбран только новый `tree 2.2.1-r2`, без обновления, удаления или переустановки
нативных пакетов. Исходные и скопированные DB/world/список защиты/индексы
остались неизменными. Это проверка решения зависимостей, без установки пакета
на роутер. Она не заменяет проверку свободного места и работы пакета на устройстве.

ASU использует отдельно проверенные замороженные официальные индексы.
Допустимый отдельный набор OpenWrt выбирает оператор; дистрибуции внутри
одного набора не смешиваются. Каталог ASU для recommended APK ещё ожидает
отдельного продвижения и проверки;
проверка образа из подписанного live-снимка ASU здесь не заявляется.
Публичный доступ к ASU Linux 6.6 пока блокирует Cloudflare; работоспособность
этого публичного маршрута не подтверждена.

## Ежедневные обновления

Ежедневно в 03:17 UTC проверяются feeds, официальный stable Tailscale,
согласованная стабильная пара PBR/LuCI автора MOSSDeF и рецепт AmneziaWG
из `2Grey/awg-openwrt`. AWG следует версии упаковщика, а не напрямую
каждому релизу Amnezia. Пакеты собираются из SDK своего канала; нативное
ядро, штатные kmods и защищённые зависимости сохраняются. Каналы
обрабатываются последовательно; сбой не заменяет последнюю публикацию.

Каталог **Attended Sysupgrade** и официальные APK-индексы не обновляются
от ежедневной публикации feed: оператор отдельно проверяет и продвигает
новый снимок. Все kmods, включая AmneziaWG, закреплены в ASU, а в APK —
также в установленном `world`. Поэтому свежий AWG в feed сам по себе
не обновит установленный модуль: сейчас нужно новое проверенное нативное
поколение. Версия ядра при этом может остаться прежней. Tailscale
исключён из обычных образов; ASU сохраняет его только если он уже
установлен на запрашивающем устройстве. Аппаратные испытания выполняются отдельно.

Страна Wi-Fi `DB` выбирается вручную в LuCI для каждого радио и записывает
буквальное `country=DB` только в выбранную секцию. Добавление пункта не меняет
страну по умолчанию, не форсирует мощность и не отключает DFS.
