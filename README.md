# Redmi AX6000: vendor Linux 6.12 и подписанные пакеты

Две независимые линии прошивок на базе
[chasey-dev ImmortalWrt 25.12](https://github.com/chasey-dev/immortalwrt-mt798x-rebase):

| Линия | Ядро | Закреплённые исходники | Назначение |
| --- | --- | --- | --- |
| recommended | 6.12.108 | `ae65e1de69971b5a2e3cf7e39390ee93f274d488` | Первое испытание на stock layout |
| latest | 6.12.112 | `a99b0888b88f134f56bcb2a7d93027b5d20638a9` | Экспериментальная линия с известными сообщениями о регрессиях HNAT |

Каждая линия собирает **stock, mtkuboot и ubootmod**. Закрытые Wi-Fi-драйверы
MediaTek и штатный vendor-стек сохранены. SDK и полный банк применимых модулей
ядра выпускаются вместе с прошивкой; две линии имеют отдельные ABI и feeds.

**Публикация 6.12 готовится.** Ссылки на готовые образы и результаты реальной
сборки появятся после независимой проверки образов и свежей сборки из SDK.
Уже готовая линия Linux 6.6 доступна в
[ax6000-packages](https://github.com/valujin/ax6000-packages).

## Пакеты

Tailscale из официального стабильного ARM64-архива, AmneziaWG 3.1,
WireGuard, OpenVPN, IPsec/strongSwan, PBR, mwan3, banIP, GeoIP-инструменты,
LuCI и русский интерфейс. Часть пакетов доступна для последующей установки;
состав образа указан в `image_packages` соответствующего source-профиля.
Используется opkg/IPK с обязательной проверкой подписей.

## Подключение

Прошивка устанавливается владельцем вручную. Начинать испытания со stock layout;
образы других разметок требуют соответствующего загрузчика и разделов flash.
[Инструкция проверки](docs/FLASH.md) описывает последовательность.
После установки соответствующей прошивки проверить сеть и выполнить на роутере:

```sh
opkg status kernel
ax6000-install-feed
```

Встроенная команда сверяет точный ABI, архитектуру и закреплённый ключ,
проверяет подпись индекса, сохраняет настройки opkg и подключает feed своей
линии. Другие активные feeds отключаются; сами пакеты не устанавливаются.
Модули этой линии несовместимы с исходной прошивкой 6.6.95 и с другой линией.

## Обновления и проверки

Ежедневный монитор отслеживает feeds 25.12, AmneziaWG и стабильный Tailscale.
База прошивки и штатные модули остаются закреплёнными; свежие пакеты и
AmneziaWG собираются из SDK конкретной прошивки. Обновление одного канала
сохраняет второй канал побайтно. Ошибка сборки, подписи или публикации
сохраняет последний успешно опубликованный набор.

Прошивки и SDK хранятся в неизменяемых GitHub Releases; подписанные IPK — на
GitHub Pages. Проверка включает содержимое трёх образов, vendor-драйверы,
ABI модулей, SHA256 SDK и отдельную сборку из экспортированного SDK.
Она не подтверждает загрузку, производительность или работу HNAT на физическом
роутере. Регрессии latest нужно проверять и при использовании как роутера.

Локально разрешена одна тяжёлая сборка одновременно с лимитами 4 CPU,
10 GiB RAM и без swap. Существующие сервисы сервера не изменяются.
