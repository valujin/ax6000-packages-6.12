# Xiaomi AX3000T — стоковая разметка, MediaTek EasyMesh

Тестовая сборка для MediaTek MT7981 RD03/RD23. Не подходит для Qualcomm RD03v2 или разметки ubootmod. Загрузчик не заменяет.

Основа: ImmortalWrt 25.12-SNAPSHOT, Linux 6.12.108, проприетарный mt_wifi 7.6.7.3. Менеджер пакетов — APK; встроены MediaTek WAPP, 1905daemon, mapd и интерфейс EasyMesh для подключения к нашим AX6000. ASU и Tailscale в образ не включены.

## Файлы

- `*-squashfs-sysupgrade.bin` — постоянная система для обновления совместимого OpenWrt/ImmortalWrt со стоковой разметкой. При первом переходе с другой сборки переносить настройки вручную.
- `*-initramfs-factory.ubi` — временная система для процедуры первоначальной установки на стоковую разметку. Это не файл для загрузки в штатный веб-интерфейс Xiaomi.
- `*-initramfs-kernel.bin` — временный initramfs-образ для поддерживаемого способа загрузки.
- `SHA256SUMS` — контрольные суммы.
- `verification.json` — результаты проверки содержимого образов.

Конкретная процедура первоначальной установки зависит от текущей прошивки и доступного способа восстановления. Не использовать команды записи разделов от AX6000.

## EasyMesh

После установки EasyMesh выключен. Для дополнительного узла откройте MediaTek Mesh, выберите роль дополнительного узла и проводное либо беспроводное подключение, затем выполните сопряжение с контроллером AX6000. При проводном подключении используется WAN-порт узла и LAN-порт контроллера. После подключения управляющий адрес узла выдаёт контроллер.

В образ включён именно фирменный стек MediaTek EasyMesh. Обновления настроек MU-MIMO, снимки конфигурации и откат адаптированы к MT7981.

## Границы проверки

Сборка и статическая проверка образов не заменяют испытания на устройстве. Загрузка AX3000T, работа радио и сопряжение AX3000T–AX6000 на реальном оборудовании ещё не проверены. Синхронизация изолированных гостевых VLAN для AX3000T не активирована: существующее подтверждение изоляции относится только к AX6000.

Публичные пользовательские APK-репозитории сохранены с тегом `@public` (например, `apk add iperf3@public`). Репозиторий ядра/драйверов AX6000 не подключён: его vendor-пакеты нельзя подменять на AX3000T.

Проверка выпуска: сборка завершилась с кодом 0; проверены 299 пакетов, 50 runtime-файлов Mesh в squashfs и initramfs, UBI/FIT и 13 ключевых vendor-файлов. Независимый прогон 14 тестов адаптации AX3000T и 12 тестов конфигурации/проверщика прошёл.
